First public release of Cyclop for Windows 11 (x64).

### Downloads

- **CyclopWindows.exe**: standalone executable; download and run. No Python installation required. Its first launch can take longer while bundled files are extracted.
- **CyclopWindows-win-x64.zip**: portable folder build. Extract it and run `CyclopWindows/CyclopWindows.exe`, keeping `_internal` alongside it. Use this option for faster startup.
- **SHA256SUMS.txt**: checksums for both downloads.

Quit the previous copy from its tray menu before launching this version. Existing local notes, snippets and settings are preserved. The builds are unsigned. Optional offline translation models are installed separately from source.

### Fixes included

- Long YouTube/media titles use two complete lines with an ellipsis; hover to read the full title. Artist, source and playback controls stay visible.
- Snippet editors and file pickers stay above the panel so their fields and Save/Cancel buttons remain accessible.
- Open dialogs and dropdowns prevent delayed hover events from switching tools, avoiding apparently unresponsive controls.
- Currency selectors offer choices on first launch, before downloading rates. Conversion clearly requires fetched or cached rates; network failures leave Fetch rates available for retry.
- Dropdown windows stay above the panel, including currency, notes and display selection.
- Faster opening, closing and tab-hover response; switching equal-height tabs no longer starts an unnecessary resize animation.

### Validation

Automated functionality tests, Windows desktop interaction and window-stacking checks, native WinRT checks, and startup/clean-exit checks for both packaged executables run before publication. Real media-player behavior and multiple-monitor DPI transitions still depend on the Windows desktop configuration.
