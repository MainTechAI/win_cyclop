Cyclop for Windows 11 (x64) 0.2: a 3D Cyclop eye, screen text capture, voice commands, keep-awake and volume controls.

### Downloads

- **CyclopWindows.exe**: standalone executable; download and run. No Python installation required. Its first launch can take longer while bundled files are extracted.
- **CyclopWindows-win-x64.zip**: portable folder build. Extract it and run `CyclopWindows/CyclopWindows.exe`, keeping `_internal` alongside it. Use this option for faster startup.
- **SHA256SUMS.txt**: checksums for both downloads.

Quit the previous copy from its tray menu before launching this version. Existing local notes, snippets and settings are preserved. The builds are unsigned. The speech model for voice commands and transcription downloads once, on first use. Optional offline translation models are installed separately from source.

### New

- **Cyclop**: a 3D eye beside the notch (red by default). It looks around, follows the pointer and blinks, and slides up out of the way when idle; hover to bring it back. Click it for a voice command or to open the panel.
- **System stats** (optional): CPU, RAM, GPU and temperature as colour-coded numbers under Cyclop.
- **New icon**: the eye as a flat 2D icon for the executable and tray.
- **Image → text**: **Ctrl+Shift+X**, drag around any text on screen; offline Windows OCR copies it. New Text capture tab.
- **Define / translate selection**: **Ctrl+Alt+D** shows a definition popup (Wiktionary); **Ctrl+Alt+T** translates the selection in its own window (offline).
- **Voice commands** (off by default): **Ctrl+Alt+V** or click Cyclop. English and Russian: open apps, web search, volume, play/pause/next, lock, text capture, keep awake, switch tabs. Only a fixed list of safe actions can run.
- **Recorder** tab: record the microphone and transcribe offline.
- **Quick settings** flyout in the Windows 11 style, with a **Keep awake** tile and output volume. Keep awake is also in the tray menu.
- **Volume** sliders in Music: the playing app (e.g. the browser playing YouTube) and overall output.
- **Tabs cycle in a loop** with Ctrl+Tab, the mouse wheel or a click on the tab title.
- Every feature can be turned off in Settings, and all global shortcuts can be changed there.

### Fixes included

- A single click on the tray icon no longer opens the panel and instantly closes it.

### Validation

Automated functionality tests, Windows desktop interaction and window-stacking checks, native WinRT and OCR projection checks, and startup/clean-exit checks for both packaged executables (including the 3D mascot render) run before publication. Microphone, OCR languages, temperature sensors and per-app volume depend on the Windows configuration of each PC.
