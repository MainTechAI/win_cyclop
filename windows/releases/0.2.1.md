Cyclop for Windows 11 (x64) 0.2.1: a livelier Cyclop with red sonar, working stats and clicks.

### Downloads

- **CyclopWindows.exe**: standalone executable; download and run. No Python installation required. Its first launch can take longer while bundled files are extracted.
- **CyclopWindows-win-x64.zip**: portable folder build. Extract it and run `CyclopWindows/CyclopWindows.exe`, keeping `_internal` alongside it. Use this option for faster startup.
- **SHA256SUMS.txt**: checksums for both downloads.

Quit the previous copy from its tray menu before launching this version. Existing local notes, snippets and settings are preserved. The builds are unsigned.

### New

- **Cyclop is alive**: it breathes and floats, tilts its head, hops, looks around while scanning with **red sonar** pulses and a radar sweep, perks up when the pointer comes near, bounces when clicked, shakes on errors and dozes off when left alone.
- **Text capture** (Ctrl+Shift+X) shows a red sonar sweep over the selected area while Cyclop stares at it and reads the text.

### Fixes included

- Clicking the eye opens the panel (and clicking again closes it). A double-click no longer cancels itself out.
- CPU, RAM, GPU and temperature now show under Cyclop by default, including after upgrading from 0.2.0, and stay visible when Cyclop tucks away. Turn them off in Settings → System stats.

### Validation

Automated functionality tests, Windows desktop interaction checks (including a real mouse click on Cyclop), native WinRT and OCR checks, and startup/clean-exit checks for both packaged executables (including the mascot render and a live CPU/memory reading) run before publication.
