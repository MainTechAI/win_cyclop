Cyclop for Windows 11 (x64) 0.2.3: the webcam option finds and opens your camera reliably.

### Downloads

- **CyclopWindows.exe**: standalone executable; download and run. No Python installation required. Its first launch can take longer while bundled files are extracted.
- **CyclopWindows-win-x64.zip**: portable folder build. Extract it and run `CyclopWindows/CyclopWindows.exe`, keeping `_internal` alongside it. Use this option for faster startup.
- **SHA256SUMS.txt**: checksums for both downloads.

Quit the previous copy from its tray menu before launching this version. Existing local notes, snippets and settings are preserved. The builds are unsigned.

### Fixes included

- "Look where I look" no longer reports "No camera found" on PCs whose camera works in other apps. Cyclop opens the camera through Media Foundation, which supports Windows 11 camera sharing, before falling back to DirectShow. If the chosen camera fails it tries the others (some laptops list an infrared camera first), and it checks that frames actually arrive.
- If the camera is busy, Cyclop says so, explains what to check, keeps following the mouse, and retries every 20 seconds. There is no need to toggle the option.
- Settings shows which camera is in use.

### Validation

Automated functionality, behaviour and camera fallback tests, Windows desktop interaction checks, native WinRT and OCR checks, and startup/clean-exit checks for both packaged executables run before publication.
