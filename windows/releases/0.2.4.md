Cyclop for Windows 11 (x64) 0.2.4: the project is now Windows-only, with a refreshed README and small polish.

### Downloads

- **CyclopWindows.exe**: standalone executable; download and run. No Python installation required. Its first launch can take longer while bundled files are extracted.
- **CyclopWindows-win-x64.zip**: portable folder build. Extract it and run `CyclopWindows/CyclopWindows.exe`, keeping `_internal` alongside it. Use this option for faster startup.
- **SHA256SUMS.txt**: checksums for both downloads.

Quit the previous copy from its tray menu before launching this version. Existing local notes, snippets and settings are preserved. The builds are unsigned.

### Changes

- Cyclop's red sonar rings are no longer cut off on one side while the panel is closed.
- The repository now contains only the Windows 11 app: the original macOS sources and their tooling were removed (the original project is credited and linked in the README).
- New README with a current preview of the panel and Cyclop, and English contributing, security and issue templates.

### Validation

Automated functionality, behaviour and camera tests, Windows desktop interaction checks (including a real mouse click on Cyclop), native WinRT and OCR checks, and startup/clean-exit checks for both packaged executables run before publication.
