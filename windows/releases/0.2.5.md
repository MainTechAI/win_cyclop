Cyclop for Windows 11 (x64) 0.2.5: arrange the panel tabs your way, and see the installed version in Settings.

### Downloads

- **CyclopWindows.exe**: standalone executable; download and run. No Python installation required. Its first launch can take longer while bundled files are extracted.
- **CyclopWindows-win-x64.zip**: portable folder build. Extract it and run `CyclopWindows/CyclopWindows.exe`, keeping `_internal` alongside it. Use this option for faster startup.
- **SHA256SUMS.txt**: checksums for both downloads.

Quit the previous copy from its tray menu before launching this version. Existing local notes, snippets and settings are preserved. The builds are unsigned.

### New

- **Rearrange the tabs** in Settings → Panel tabs: drag a tab, or use Move up / Move down, to change its position. Move it above or below the divider to put it on the left or right rail, and untick it to hide it. Changes apply immediately and are remembered; Reset order restores the default. Tab cycling (Ctrl+Tab, mouse wheel) follows your order, and the panel grows if one rail gets long.
- **Version in Settings**: the bottom of Settings shows the installed version, with buttons for its release notes and the latest release.

### Validation

Automated functionality, behaviour, arrangement and camera tests, Windows desktop interaction checks (including a real mouse click on Cyclop), native WinRT and OCR checks, and startup/clean-exit checks for both packaged executables run before publication.
