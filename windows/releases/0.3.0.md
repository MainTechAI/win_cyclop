Cyclop for Windows 11 (x64) 0.3.0: a living eye. Cyclop now stays out long enough to be seen, plays real idle behaviours, and reacts to what you do on your PC.

### Downloads

- **CyclopWindows.exe**: standalone executable; download and run. No Python installation required. Its first launch can take longer while bundled files are extracted.
- **CyclopWindows-win-x64.zip**: portable folder build. Extract it and run `CyclopWindows/CyclopWindows.exe`, keeping `_internal` alongside it. Use this option for faster startup.
- **SHA256SUMS.txt**: checksums for both downloads.

Quit the previous copy from its tray menu before launching this version. Existing local notes, snippets and settings are preserved. The builds are unsigned.

### New

- **Idle life.** When the mouse rests for a moment, Cyclop plays short acts: patrolling the screen with red sonar, hunting a spot (with a red sonar mark appearing there), peering at the pointer, double takes, nods and head shakes, rolling its eye, stretching, and spinning its iris. When left alone or late at night it yawns, dozes and jolts awake.
- **Peeking.** While tucked away it slides halfway out now and then, looks around with a ping, and tucks back.
- **It notices your PC.** It glances at windows you switch to, watches the text cursor while you type, gulps things you copy, bobs to music, and breathes fast, trembles and glows when the CPU is maxed or the PC runs hot.
- **New reactions.** Shake the mouse near it to make it dizzy (this works at the top edge of the screen), and rest the pointer on it to make it giggle.
- **New settings** (Settings → Cyclop mascot): size (bigger by default), liveliness (Calm, Lively, Playful), peeking, glancing at windows and the text cursor, and red sonar marks on the screen.

### Fixes included

- Cyclop no longer hides 8 seconds after you hover it, before any behaviour could start. The default is now 30 seconds, and an unchanged 8-second setting is updated automatically.
- Hops and jolts bounce downward, away from the screen edge, so they are visible.
- Long media titles without spaces wrap and end with "…" instead of running off the panel.

### Validation

Automated functionality, behaviour-engine, reaction and camera tests, Windows desktop interaction checks (including a real mouse click on Cyclop), native WinRT and OCR checks, and startup/clean-exit checks for both packaged executables run before publication.
