Cyclop for Windows 11 (x64) 0.3.1: a lighter Cyclop. Every feature from 0.3.0 now runs with about half the CPU at rest and less memory, and a few bugs are fixed.

### Downloads

- **CyclopWindows.exe**: standalone executable; download and run. No Python installation required. Its first launch can take longer while bundled files are extracted.
- **CyclopWindows-win-x64.zip**: portable folder build. Extract it and run `CyclopWindows/CyclopWindows.exe`, keeping `_internal` alongside it. Use this option for faster startup.
- **SHA256SUMS.txt**: checksums for both downloads.

Quit the previous copy from its tray menu before launching this version. Existing local notes, snippets and settings are preserved. The builds are unsigned.

### Lighter

- **About half the CPU at rest** (≈5.6 % of one core instead of ≈10.5 %), and less than half while Cyclop is tucked away. Recently drawn eye frames are reused, the screen is repainted only when the eye visibly changes, and Cyclop slows its frame rate when it is calm or hidden.
- **About 35–50 MB less memory.** Speech recognition, volume control and other optional parts load only when you first use them, and the speech model is released after five unused minutes. It loads again the next time you record or speak.
- Lighter background checks: music is checked for "is something playing" only while the Music tab is closed, and global hotkeys are handled with less work.

Cyclop's animations look the same as before (rendered frames differ by under 1/255).

### Fixes included

- Fixed a possible crash when a red sonar mark faded out while Cyclop was still tracking it.

### Validation

Automated functionality, behaviour-engine, reaction and camera tests, Windows desktop interaction checks (including a real mouse click on Cyclop), native WinRT and OCR checks, and startup/clean-exit checks for both packaged executables run before publication.
