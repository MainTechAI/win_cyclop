Cyclop for Windows 11 (x64) 0.4.0: about twice as fast to start. The exe is a quarter of its former size (43 MB instead of 177 MB); speech recognition and webcam gaze are now add-ons that download the first time you turn them on.

### Downloads

- **CyclopWindows.exe**: standalone executable; download and run. No Python installation required.
- **CyclopWindows-win-x64.zip**: portable folder build. Extract it and run `CyclopWindows/CyclopWindows.exe`, keeping `_internal` alongside it. Use this option for the fastest startup.
- **CyclopSpeech-0.4.0-win-x64.zip** and **CyclopCamera-0.4.0-win-x64.zip**: the add-ons. You don't need to download them yourself: Cyclop fetches the one it needs when you turn on the feature.
- **SHA256SUMS.txt**: checksums for all downloads.

Quit the previous copy from its tray menu before launching this version. Existing local notes, snippets and settings are preserved. The builds are unsigned.

### Faster start

The one-file exe unpacks itself every time it starts. Measured on Windows, that unpacking was most of the wait: 462 MB, mostly features that are off by default. What start-up cost, most expensive first:

| | Start-up cost in 0.3.1 | Now |
|---|---|---|
| Speech recognition engine (Whisper, FFmpeg, ONNX Runtime) | ~200 MB unpacked on every launch | An add-on: downloads once (71 MB) when you turn on voice commands or transcribe a recording |
| Webcam gaze (OpenCV) | ~112 MB unpacked on every launch | An add-on: downloads once (42 MB) when you turn on "Look where I look" |
| Files no feature used (software OpenGL, Qt translations and networking, Pillow, Windows API stubs) | ~50 MB | Left out |
| Time-zone data for the calendar | ~600 tiny files | One file |
| System-stats sensors (PDH, NVIDIA) | ~0.25 s at launch | Start 1.5 s after Cyclop appears |
| Windows media sessions (music) | ~0.2 s at launch | Start 1.5 s after Cyclop appears, or when you open Music |

Launched alternately on the same Windows PC, the exe was up and running in 2.4–2.6 s instead of 4.8–5.6 s, and the portable build shows the eye in about 0.75 s instead of 0.95 s.

### Add-ons

- They are off by default, as these features already were. Turning one on in Settings (or pressing Transcribe in the Recorder) downloads it once from this release, with progress in Settings and from Cyclop.
- A download is installed only if its size and SHA-256 match the values built into this version. It goes to the `addons` folder in Cyclop's data folder, and add-ons of older versions are removed.
- If voice commands or the webcam option were already on, Cyclop downloads the add-on by itself the first time this version starts.

### Validation

Automated functionality, behaviour-engine, add-on, reaction and camera tests, Windows desktop interaction checks (including a real mouse click on Cyclop), and native WinRT and OCR checks run before publication. Both packaged executables pass startup and clean-exit checks. In those checks each executable installs both add-ons from the build and uses them (FFmpeg audio decoding, Silero voice detection and OpenCV face detection); the portable build also downloads a Whisper model and transcribes with it.
