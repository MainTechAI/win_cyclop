Cyclop for Windows 11 (x64) 0.4.2: quitting during an add-on download is immediate.

### Downloads

- **CyclopWindows.exe**: standalone executable; download and run. No Python installation required.
- **CyclopWindows-win-x64.zip**: portable folder build. Extract it and run `CyclopWindows/CyclopWindows.exe`, keeping `_internal` alongside it. Use this option for the fastest startup.
- **CyclopSpeech-0.4.2-win-x64.zip** and **CyclopCamera-0.4.2-win-x64.zip**: the add-ons. You don't need to download them yourself: Cyclop fetches the one it needs when you turn on the feature.
- **SHA256SUMS.txt**: checksums for all downloads.

Quit the previous copy from its tray menu before launching this version. Existing local notes, snippets and settings are preserved. The builds are unsigned. An add-on you installed with an earlier version is downloaded again for 0.4.2 the next time you use it.

### Fixes

- Quitting Cyclop while an add-on is downloading no longer waits for the network: even when the connection has stalled or is still being made, Cyclop quits within a fraction of a second.
- The developer start-up profiler removes its temporary data folder however it exits.

### Validation

Automated functionality, behaviour-engine, add-on (including quitting during a stalled download), reaction and camera tests, Windows desktop interaction checks (including a real mouse click on Cyclop), and native WinRT and OCR checks run before publication. Both packaged executables pass startup and clean-exit checks, installing both add-ons from the build and using them.
